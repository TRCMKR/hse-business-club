# F8 — Визуальный стиль в духе сайта Бизнес-клуба

**Зависимости:** F0–F5 смержены (все экраны на месте, UI-кит и токены в `front/app/assets/css/main.css`).
**Блокирует:** F6 (QA, тёмная тема и a11y проверяются уже на новом стиле).
**Читать:** `SPEC.md` §7 (абзац «Визуальный стиль»), `tasks/DECISIONS.md` (запись о F8), отчёт
`tasks/reports/F0.md` (токены, UI-кит), `front/app/assets/css/main.css`, `front/nuxt.config.ts`
(`@nuxt/fonts`), `front/app/components/{ui,nav,cards}/**`, `front/app/layouts/**`.
**Референс:** сайт https://hsebusinessclub.ru (посмотреть в браузере; скриншоты, если есть, в
scratchpad координатора — путь в брифе). Делать **в духе, не 1 в 1**: это mini-app внутри
Telegram, а не промо-лендинг.

## Что сделать

1. **Токены** `main.css`: новая палитра (светлая + тёмная), `--font-family: 'Montserrat', …`,
   радиусы, тени; все компоненты UI-кита должны «переодеться» через токены, без
   переписывания. Проверить контраст текста/фона ≥ 4.5:1 и кнопок ≥ 3:1 в обеих темах.
2. **Шрифт**: `nuxt.config.ts` → `@nuxt/fonts` Montserrat (веса 400/500/600/700, subset
   cyrillic+latin), убрать Inter. Проверить, что шрифт реально применяется (SSR, нет FOUT
   заметного дольше ~100 мс — `font-display: swap`).
3. **Навигация**: `app-header` (десктоп) и `tab-bar` (мобильный) — navy-фон, белый текст,
   активный пункт — синий/жёлтый маркер; логотип/название «Бизнес-клуб · Стартапы и
   вакансии» (текстовый, без логотипа ВШЭ — чужой бренд не копируем). `create-fab` — синий
   градиент. Safe-area на мобильном сохранить.
4. **Компоненты**: `button` (primary — градиент/синий, secondary — прозрачная с синей рамкой,
   ghost, danger), `card`/`listing-card`/`application-card` (radius 16, мягкая тень, hover на
   десктопе), `badge`/`chip` (мягкие заливки из палитры), `segmented`/`tabs` (активный —
   navy/синий), `page-header` (крупный заголовок 700), `empty-state`/`error-state` (иконка в
   синем круге), `skeleton` (под новый фон), `dialog`/`sheet` (radius 20 сверху у sheet).
   Страницы входа/регистрации — navy-«шапка» или фон с заголовком клуба, форма на светлой
   карточке.
5. **Экраны F1–F5**: пройти все экраны на 375px и 1280px, поправить локальные стили страниц,
   если они противоречат новой палитре (hardcoded цвета → токены). Ничего функционального
   не менять.
6. **Скриншоты** «до/после» 375/1280 для 4 ключевых экранов (login, лента, детали, профиль)
   в `front/docs/screenshots/` (перезаписать F0-шные) — пойдут в README.
7. Тесты: обновить снапшоты/селекторы, если изменились классы; `npm run lint`, `npm run
   test`, `npm run build` зелёные.

## Критерии приёмки

- [ ] На всех экранах применяется Montserrat; палитра navy/синий/жёлтый узнаётся, но
      интерфейс не копия сайта (нет его блоков, картинок, логотипа).
- [ ] Светлая и тёмная темы: контраст текста ≥ 4.5:1 (проверить axe/devtools на 3 экранах).
- [ ] Жёлтый — не более чем в двух типах элементов.
- [ ] 375px и 1280px без горизонтального скролла; tab-bar/safe-area работают.
- [ ] `npm run lint`, `npm run test`, `npm run build` зелёные; скриншоты приложены.
