# F1 — Лента

**Зависимости:** F0. **Блокирует:** F6.
**Читать:** `SPEC.md` §4.1 (`V1ListListings`), §7; `tasks/reports/F0.md`.

## Что сделать

`pages/index.tsx` + `components/feed/*`:

1. Фильтры: `segmented` Все / Стартапы / Вакансии ↔ query `kind`; поиск ↔ query `q`
   (debounce 300ms, кнопка очистки). Состояние в URL, чтобы ссылка воспроизводила выдачу.
2. Список `listing-card` (из F0), клик → `/listings/:id`. Первая страница — SSR
   (`useAsyncData` с ключом от фильтров). «Показать ещё» докладывает страницы
   (`page+1`), по достижении `total` — «Это всё». Смена фильтра сбрасывает на страницу 1.
3. Состояния: скелетоны (3 карточки) при загрузке первой страницы; у «Показать ещё» —
   `loading`; пусто без фильтров — «Пока нет предложений» + CTA «Создать публикацию»;
   пусто с фильтрами — «Ничего не нашлось» + «Сбросить фильтры»; ошибка — `error-state` с
   «Повторить».
4. Раскладка: 1 колонка до 1024px, 2 колонки от 1024px. FAB «Создать» на мобильном.
5. Тесты: композабл `useFeed` (сброс страницы при смене фильтра, накопление items,
   `hasMore`), компонент фильтров (debounce, URL).
