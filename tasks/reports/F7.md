# F7 — отчёт: `@fe/blob-avatar`

Ветка `task/F7`. Зона: `front/lib/blob-avatar/**` (вне зоны правок нет, кроме этого отчёта).

## Что сделано

Пакет `front/lib/blob-avatar` (`@fe/blob-avatar`): чистый TypeScript без runtime-зависимостей +
Vue-компонент (`vue` — только `peerDependencies: 3.x`). `dist/` собран и закоммичен (vite lib,
`preserveModules`, + `.d.ts` через `tsc`), `npm run build` диффа не даёт.

Структура `src/`:

| файл | что |
|---|---|
| `random.ts` | `normalizeSeed` (`trim().toLowerCase()`), `hashString` (FNV-1a 32 + fmix32), `createRng` (mulberry32: `next`, `pick`, `range`, `int`). `Math.random` не используется. |
| `traits.ts` | контракт `Traits`, наборы вариантов, `deriveTraits(seed, overrides?)` — по одному вызову rng на ось в фиксированном порядке, квантование в вариант. |
| `shapes.ts` | 8 силуэтов + точка лица и блик для каждого; `blob` — Catmull-Rom → кубические Безье через 6–9 точек. |
| `faces.ts` | глаза (4 формы, размер/расстояние/наклон/взгляд), брови и рты для 10 выражений, румянец/веснушки. |
| `colors.ts` | палитра из hue/tone (HSL → hex). |
| `svg.ts` | `SvgNode`, `toSvgString` (экранирование атрибутов, числа до 2 знаков). |
| `render.ts` | `buildTree(traits, options)` — фон, тело, блик, лицо. |
| `index.ts` / `vue.ts` | публичное API / компонент `BlobAvatar`. |

## API пакета

```ts
import { blobAvatar, blobAvatarTree, deriveTraits } from '@fe/blob-avatar';
blobAvatar(seed, { size?, background?: 'none'|'circle'|'squircle'|'square', aria?, traits?: Partial<Traits> }): string
blobAvatarTree(seed, options?): SvgNode
deriveTraits(seed, overrides?): Traits
// плюс buildTree, toSvgString, hashString, createRng, normalizeSeed, SHAPES/HUES/TONES/EYE_SHAPES/EXPRESSIONS/EXTRAS и типы

import { BlobAvatar } from '@fe/blob-avatar/vue';
// props: seed: string; size?: number; background?; traits?: Partial<Traits>; label?: string
```

По умолчанию: `background: 'circle'`, без `width/height` (SVG тянется на контейнер),
`aria-label` = нормализованный seed (`trim().toLowerCase()`), пустой → `'avatar'`; метка
обрезается до 64 символов (`MAX_LABEL_LENGTH`). Значения `traits` вне наборов вариантов (или
вне `0..1` для непрерывных осей) игнорируются — берётся выведенное из seed. Компонент рендерит через `h()` по дереву (без `innerHTML`), `computed` по
пропсам; SSR-разметка совпадает с `blobAvatar()` (проверено тестом).

## Оси и варианты

- `shape`: `round | squircle | blob | droplet | hexagon | cloud | capsule | triangle`; `shapeSeed` (uint32) — контур `blob` и наклон тела ±5°.
- `hue`: `12, 30, 50, 140, 175, 210, 260, 320`; `tone`: `light | dark`.
- `eyeShape`: `dot | oval | wide | wink`; непрерывные `eyeSize`, `eyeSpacing`, `eyeTilt`, `pupilShift` (`0..1`).
- `expression`: `happy | neutral | surprised | smirk | sleepy | mad | thinking | cheeky | sad | shy`.
- `extras`: `blush | freckles | none`.

Отклонение от формулировки задачи: оси глаз сделаны плоскими полями `Traits`
(`eyeSize`, `eyeSpacing`, `eyeTilt`, `pupilShift`, `eyeShape`), а не вложенным объектом `eyes`,
чтобы `overrides: Partial<Traits>` закреплял их без глубокого merge. Добавлена ось `shapeSeed`.

## Проверки (критерии приёмки)

- Runtime-зависимостей нет; `vue` — peer; `npm run build` без диффа в `dist/`.
- `npm test` — 24 теста зелёные: детерминизм (`blobAvatar('Anna ') === blobAvatar('anna')` — строгое равенство всей строки, включая `aria-label`), 200 seed → ≥ 195 уникальных,
  все 640 комбинаций `shape × expression × eyeShape × tone` без `NaN/undefined` и парсятся
  `DOMParser` (jsdom) без `parsererror`, без `id/style/script/href`; < 4 КБ (в т. ч. «тяжёлая»
  конфигурация); снапшоты `anna, boris, vera, dmitry` (трейты + SVG) в
  `tests/__snapshots__/avatar.test.ts.snap`; `BlobAvatar` монтируется и выдаёт `<svg role="img">`;
  SSR через `vue/server-renderer` совпадает с `blobAvatar()`; невалидные `overrides` игнорируются;
пустой seed → `aria-label="avatar"`, seed длиной 100 000 символов → SVG < 4 КБ.
- Размер: демо-аккаунты 1.2–1.6 КБ, максимум на 5000 случайных seed — ~2 КБ.
- Node ≡ браузер: галерея бандлит `src/index.ts` и повторно рендерит все 188 аватаров в Chrome —
  «все 188 SVG совпадают с Node байт в байт».
- Читаемость глаз и рта на 8 hue × 2 tone проверена глазами (секция галереи «Читаемость»).

## Подключение в Nuxt (для координатора, после merge F0 и F7)

1. `front/package.json`, в `dependencies`:
   ```json
   "@fe/blob-avatar": "file:lib/blob-avatar"
   ```
   затем `npm i` в `front/` (пакет отдаёт готовый `dist/`, сборка не нужна).
2. В `front/app/components/ui/avatar/index.tsx` заменить заглушку:
   ```tsx
   import { BlobAvatar } from '@fe/blob-avatar/vue';
   // …
   {props.avatarUrl
     ? <img src={props.avatarUrl} alt={props.username} width={props.size} height={props.size} />
     : <BlobAvatar seed={props.username} size={props.size} background="circle" label={props.displayName ?? props.username} />}
   ```
   Без `size` SVG занимает 100% контейнера — можно управлять размером через CSS обёртки.
3. После правок в `lib/blob-avatar` — `npm run build` в пакете.
4. Внимание: две копии Vue. `file:lib/blob-avatar` ставится симлинком; если в
   `front/lib/blob-avatar/node_modules` есть свой `vue` (dev-зависимость пакета), Vite может
   подхватить его через симлинк — компонент будет работать с другим экземпляром Vue (ломаются
   реактивность и SSR). Рекомендация: в `nuxt.config.ts` добавить
   `vite: { resolve: { dedupe: ['vue'] } }` либо не держать `node_modules` в `lib/blob-avatar`
   при dev-запуске фронта.

## Доработка по ревью (итерация 1)

- `aria-label` по умолчанию берётся из нормализованного seed (`trim().toLowerCase()`), тест
  детерминизма — строгое равенство без подмен.
- Пустая метка → `'avatar'`; метка обрезается до 64 символов (`MAX_LABEL_LENGTH`, экспортируется).
- `overrides` валидируются: значения вне наборов/диапазонов игнорируются (раньше
  `shape: 'bogus'` ронял рендер).
- Удалена неиспользуемая `renderSvg` из `src/render.ts`.
- Снапшоты демо-аккаунтов не изменились (их username и так в нижнем регистре).
