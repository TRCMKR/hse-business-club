# F7 — отчёт: `@fe/blob-avatar`

Ветка `task/F7`. Зона: `front/lib/blob-avatar/**` (вне зоны правок нет, кроме этого отчёта).

## Что сделано

Пакет `front/lib/blob-avatar` (`@fe/blob-avatar`): чистый TypeScript без runtime-зависимостей +
Vue-компонент (`vue` — только `peerDependencies: 3.x`). `dist/` собран и закоммичен (vite lib,
`preserveModules`, + `.d.ts` через `tsc`), `npm run build` диффа не даёт.

Структура `src/`:

| файл | что |
|---|---|
| `random.ts` | `normalizeSeed` (`trim().toLowerCase()`), `hashString` (FNV-1a 32 + fmix32), `createRng` (mulberry32: `next`, `pick`, `range`, `int`). `Math.random` не используется. |
| `traits.ts` | контракт `Traits`, наборы вариантов, `deriveTraits(seed, overrides?)` — по одному вызову rng на ось в фиксированном порядке, квантование в вариант. |
| `shapes.ts` | 6 базовых фигур в локальных координатах (радиус ~30); `blob` — Catmull-Rom → кубические Безье через 5–7 точек. |
| `colors.ts` | `PALETTES` — 12 пастельных палитр «фон / фигура / акцент». |
| `svg.ts` | `SvgNode`, `toSvgString` (экранирование атрибутов, числа до 2 знаков). |
| `render.ts` | `buildTree(traits, options)` — фон, фигура, акцент, деталь. |
| `index.ts` / `vue.ts` | публичное API / компонент `BlobAvatar`. |

## API пакета

```ts
import { blobAvatar, blobAvatarTree, deriveTraits } from '@fe/blob-avatar';
blobAvatar(seed, { size?, background?: 'none'|'circle'|'squircle'|'square', aria?, traits?: Partial<Traits> }): string
blobAvatarTree(seed, options?): SvgNode
deriveTraits(seed, overrides?): Traits
// плюс buildTree, toSvgString, hashString, createRng, normalizeSeed, SHAPES/ACCENTS/DETAILS/PALETTES и типы

import { BlobAvatar } from '@fe/blob-avatar/vue';
// props: seed: string; size?: number; background?; traits?: Partial<Traits>; label?: string
```

По умолчанию: `background: 'circle'`, без `width/height` (SVG тянется на контейнер),
`aria-label` = нормализованный seed (`trim().toLowerCase()`), пустой → `'avatar'`; метка
обрезается до 64 символов (`MAX_LABEL_LENGTH`). Значения `traits` вне наборов вариантов (или
вне `0..1` для непрерывных осей) игнорируются — берётся выведенное из seed. Компонент рендерит через `h()` по дереву (без `innerHTML`), `computed` по
пропсам; SSR-разметка совпадает с `blobAvatar()` (проверено тестом).

## Оси и варианты (с итерации 2)

- `shape`: `round | squircle | blob | droplet | hexagon | capsule`; `shapeSeed` (uint32) — контур `blob`.
- `palette`: индекс `0..11` в `PALETTES` (rose, sage, sand, lavender, sky, mint, peach, graphite, butter, mauve, denim, clay).
- `accent`: `orbit | ring | arc | inset | overlap | split`.
- `detail`: `none | satellite | trail`.
- Непрерывные `rotation`, `accentAngle`, `scale` (`0..1`).

Оси — плоские поля `Traits`, чтобы `overrides: Partial<Traits>` закреплял их без глубокого merge.
Подробности и таблица цветов — в `front/lib/blob-avatar/README.md`.

## Подключение в Nuxt (для координатора, после merge F0 и F7)

1. `front/package.json`, в `dependencies`:
   ```json
   "@fe/blob-avatar": "file:lib/blob-avatar"
   ```
   затем `npm i` в `front/` (пакет отдаёт готовый `dist/`, сборка не нужна).
2. В `front/app/components/ui/avatar/index.tsx` заменить заглушку:
   ```tsx
   import { BlobAvatar } from '@fe/blob-avatar/vue';
   // …
   {props.avatarUrl
     ? <img src={props.avatarUrl} alt={props.username} width={props.size} height={props.size} />
     : <BlobAvatar seed={props.username} size={props.size} background="circle" label={props.displayName ?? props.username} />}
   ```
   Без `size` SVG занимает 100% контейнера — можно управлять размером через CSS обёртки.
3. После правок в `lib/blob-avatar` — `npm run build` в пакете.
4. Внимание: две копии Vue. `file:lib/blob-avatar` ставится симлинком; если в
   `front/lib/blob-avatar/node_modules` есть свой `vue` (dev-зависимость пакета), Vite может
   подхватить его через симлинк — компонент будет работать с другим экземпляром Vue (ломаются
   реактивность и SSR). Рекомендация: в `nuxt.config.ts` добавить
   `vite: { resolve: { dedupe: ['vue'] } }` либо не держать `node_modules` в `lib/blob-avatar`
   при dev-запуске фронта.

## Итерация 2 — серьёзный стиль (без лиц, пастель)

Решение пользователя (`tasks/DECISIONS.md`, 2026-10-20 01:10): блобы с лицами слишком игривые
для бизнес-клуба. Визуал переделан, публичное API не тронуто.

**Что изменилось**

- Лица убраны полностью: удалён `src/faces.ts` (глаза, рты, брови, румянец/веснушки) и блик на
  теле; в SVG нет `#fff`/`#000` (проверяется тестом).
- Аватар — абстрактная композиция в духе иконки/логотипа: крупная базовая фигура + акцент +
  необязательная мелкая деталь (не больше 4 элементов поверх корня). Фигура слегка смещается
  от выступающего акцента (`orbit`, `overlap`), чтобы композиция оставалась уравновешенной;
  деталь всегда с противоположной от акцента стороны.
- Фигуры сокращены с 8 до 6 самых спокойных: убраны `cloud` и `triangle`; `droplet` теперь —
  круг с одним острым углом (лист/метка), `capsule` при повороте даёт диагональную «пилюлю».
- Вместо `hue × tone` (HSL) — 12 вручную подобранных пастельных палитр «фон / фигура / акцент»
  (rose, sage, sand, lavender, sky, mint, peach, graphite, butter, mauve, denim, clay): низкая
  насыщенность, высокая светлота, без чистого белого и чёрного. Акцент — приглушённый тёмный
  тон той же гаммы; `overlap` — тот же цвет с `opacity` 0.5 (мягкое наложение).
- Палитры и композиции подбирались по галерее и крупному плану 128/24 px за несколько итераций:
  увеличена фигура (иначе терялась при 24 px), кольцо смещено от центра и уменьшено (концентричное
  кольцо в круге читалось как глаз), деталь «точка цвета фона внутри фигуры» заменена на `trail`
  (вместе с дугой давала подобие лица), у `sand` затемнена фигура (слабый контраст с фоном).

**`Traits` — новый тип** (ломающее изменение типа, допустимо по заданию; потребителей вне пакета
нет): `shape`, `shapeSeed`, `palette`, `accent`, `detail`, `rotation`, `accentAngle`, `scale`.

`DETAILS`, `PALETTES` (вместо `HUES`, `TONES`, `EYE_SHAPES`, `EXPRESSIONS`, `EXTRAS`); типы

`0..11`, непрерывные — `0..1`, остальные — из наборов; всё прочее (в т. ч. старые оси вроде
