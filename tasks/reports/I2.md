### Отличие от I1

Для занятых портов README предлагает `docker-compose.override.yaml` в корне. Compose
подхватывает его сам, если не передавать `-f`, а `make up` без `COMPOSE_FILES` как раз
вызывает `docker compose` без `-f`. Проверено: `docker compose config` с таким файлом
даёт порты 18080, 18081, 13000 и `CORS_ORIGINS=http://localhost:13000`. Вариант I1 с
`COMPOSE_FILES=...` в README тоже описан. Тестовые цели бэка передают `-f` явно, поэтому
override на них не влияет.
