## Отклонения от задания

1. **Порт фронта `3000:3000`, а не `3000:8080`.** Dockerfile фронта (F0) слушает `PORT=3000`; задание расходится с ним.
2. **Консоль MinIO** публикуется отдельным сервисом `minio-console` (socat, ~10 МБ) в профиле `observability`:
   compose не умеет добавлять порты существующему сервису по профилю.
3. **`OTEL_EXPORTER_OTLP_ENDPOINT=jaeger:4317` при профиле** задаёт `make obs` (переменная окружения для
   compose). Голый `docker compose --profile observability up` спаны не экспортирует — нужно задать переменную
   (или в `.env`). Jaeger дополнительно публикует 4317 — для `make run` бэка на хосте.
4. `minio` запускается с `user: root` (как у B0): образ работает под uid 65532 и не содержит `/data`, свежий
   named volume принадлежит root.
5. Тестовый override — отдельный проект `hbc-test-env` + tmpfs для db **и** minio (задание просило только
   «публикует порты»); иначе `make test-env-down` (`down -v`) стирал бы `db_data` dev-стека.
6. Порты тестового стенда параметризованы `TEST_POSTGRES_PORT`/`TEST_MINIO_PORT` (по умолчанию 5433/9000);
   после merge `back/Makefile` строит из них дефолтные `TEST_POSTGRES_DSN`/`TEST_S3_ENDPOINT`.
