## Отступления и решения

1. **Версии зависимостей.** Свежие grpc-gateway/otel/minio-go/goose требуют `go 1.26`. Оставил `go 1.25.0`
   (как в задании и под `golang:1.25-alpine`): `go get go@1.25.0 toolchain@none` откатил их до последних
   совместимых (grpc-gateway v2.30.0, otel v1.46.0, minio-go v7.3.0, goose v3.27.0, …).
2. **golangci-lint.** Установленный 2.7.2 собран go1.25 и падает (panic в go/types) на стандартной библиотеке
   локального go 1.27. `make lint` запускает `go run …/golangci-lint@v2.13.2` (собирается локальным Go,
   переопределяется `GOLANGCI_LINT=`). `.golangci.yaml` — из blanc-back + `build-tags: [integration, e2e]`,
   исключён `pkg/api`, убран дубликат `unused`.
3. **MinIO-образ.** `minio/minio` больше не публикуется на Docker Hub (`pull access denied`; quay.io —
   `unauthorized`). В `docker-compose.test.yaml` — `cgr.dev/chainguard/minio:latest` (апстримный бинарь MinIO,
   RELEASE.2026-09-22), `command: server /data`, `user: root`, healthcheck через bash `/dev/tcp` (в образе нет
   `mc`/`curl`). **I0 должен взять тот же образ.**
4. **otelgrpc** больше не содержит интерцепторов — трейсинг gRPC подключён stats handler'ом (сервер и клиент
   gateway); цепочка: `ChainUnaryInterceptor(recovery, prometheus, logging, auth)`.
5. **`server.New`** принимает `ctx` первым аргументом (нужен для `RegisterGateway`); проверки `/readyz`
   добавляются `AddReadinessCheck`, публичные методы и swagger сервис отдаёт через необязательные интерфейсы
   `PublicMethods()`/`SwaggerJSON()` — сигнатура из задания сохранена в остальном.
6. **`db.Migrator{Schema, FS, Dir}`** — по заданию; в ARCHITECTURE §6 написано `Migrator{Schema, FS, VersionTable}`.
   Таблица версий не настраивается, всегда `<schema>.goose_db_version` (константа `db.VersionTable`).
   Пустая/отсутствующая папка миграций — не ошибка. `WithTx` передаёт в `fn` и `ctx`, и `pgx.Tx`.
7. **Порты** — сигнатуры и типы один в один с ARCHITECTURE §2. Отличия только оформления: константы по одной
   на строку (вместо `;`), добавлены doc-комментарии; русские комментарии-контракт из документа сохранены.
   В `apperr` добавлен `Kind.String()` (для логов). ARCHITECTURE не правил.
8. **`middleware.RealIP` в chi 5.5 deprecated** (подмена IP) — заменён на `ClientIPFromXFF` с доверием только
   loopback и приватным сетям; IP клиента и request id передаются в gRPC metadata (`x-client-ip`,
   `x-request-id`) и попадают в лог вызова. Ответ содержит `X-Request-Id`.
9. **Debug-порт** проксирует `/v1/*` в публичный роутер, чтобы «Try it out» в Swagger UI на :8081 работал без CORS.
   Swagger UI — с jsdelivr (`swagger-ui-dist@5.17.14`).
10. **Тексты ошибок gateway.** Для `Internal/Unknown/DataLoss/Unavailable/DeadlineExceeded` текст заменяется на
    «Внутренняя ошибка» (HTTP-код сохраняется, например 503 для Unavailable). Ошибки маршрутизации gateway —
    «Не найдено» (404) и «Метод не поддерживается» (405). Заглушки BFF — `Unimplemented` «Метод ещё не реализован» (501).
11. **chi-маршруты из swagger** (как в hermes): каждый путь swagger регистрируется в chi, чтобы метрики/спаны имели
    метку `route=/v1/users/{id}`; остальное уходит в gateway (`NotFound`).
12. **`/readyz`** отдаёт ключи в порядке добавления (`{"db":"ok","blob":"ok"}`), при отказе — 503 и текст ошибки
    вместо `"ok"`. Трассировка `/healthz`, `/readyz` отключена.
13. **`APP_ENV`**: допустимы `local`, `test`, `production`. В production проверяется только `JWT_SECRET` ≥ 32 байт —
    других «отладочных дефолтов» в §5 нет. Dockerfile `APP_ENV` не задаёт (решает I0; в compose демо-секрет
    для production должен быть ≥ 32 байт).
14. Параллельные субагенты не поднимались — всё сделано последовательно.

## Дыры и вопросы к документам

- ARCHITECTURE §6 (`VersionTable`) расходится с заданием B0 (`Dir`) — сделано по заданию, документ стоит поправить.
- ARCHITECTURE/SPEC/I0 упоминают `minio/minio` — образ недоступен (п. 3).
- Ошибки разбора тела запроса gateway (`InvalidArgument` с текстом protojson, напр. «proto: syntax error …»)
  не на русском, а SPEC §4.2 требует «message всегда готов к показу». Отличить их от ошибок BFF в
  `errorHandler` нельзя по коду — решение за B4 (например, оборачивать в `WithErrorHandler` по признаку
  отсутствия gRPC-ответа) или принять как есть.
- SPEC §4.2 «прочее→500»: `Unimplemented` даёт 501, `Unavailable` — 503 (дефолтный маппинг grpc-gateway);
  B4 через `errors.go` отдаёт только перечисленные коды и `Internal`, так что после B4 это не проявится.
- В swagger параметры пути — в lowerCamelCase (`/v1/listings/{listingId}/applications`), как поля protojson;
  сами URL совпадают со SPEC §4.1 (все 22 метода сверены).
- Окружение: диск Docker VM (7.8 ГБ) был заполнен на 100 % — MinIO отказывал в создании бакета («minimum free
  drive threshold»). Удалил образы, которые сам скачивал для проверки (bitnamilegacy/minio, rustfs, seaweedfs) и
  свои висячие слои hbc-back. Для I0/I1 стоит иметь в виду.
