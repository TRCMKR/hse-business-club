# hse-business-club

Тестовое задание: модуль «Стартапы и вакансии» для Telegram mini-app Бизнес-клуба НИУ ВШЭ.
Монорепо: `back/` (Go + PostgreSQL, модульный монолит: gRPC + grpc-gateway, BFF + три
bounded-context'а), `front/` (Nuxt 4, Vue 3, TSX).

- Источник истины по продукту, домену, данным и правилам — `SPEC.md`. Контракт API —
  `back/api/hbc/v1/hbc.proto`. Архитектура и порты бэкенда — `back/ARCHITECTURE.md`.
  Контракт и порты не меняются без явного указания; если без правки никак — сначала
  поправить документ, затем код, и описать изменение в отчёте.
- План и граф задач — `PLAN.md`; задания — `tasks/<ID>-*.md`; отчёты — `tasks/reports/<ID>.md`.
  Агент работает только в зоне «Владение» своей задачи; правки вне зоны — с записью в отчёт.
- Язык: UI, сообщения пользователю, README, отчёты — русский. Код, идентификаторы,
  комментарии, коммиты — английский.
- Референсы стиля (читать, не импортировать): `/Users/trcmkr/Проекты/blanc-back`,
  `/Users/trcmkr/Проекты/blanc-front`. Приватные модули (`github.com/trcmkr/hermes`) не
  использовать: репозиторий открытый, сборка в Docker без SSH.
- Перед сдачей: `back` — `make lint test`; `front` — `npm run lint && npm run test`.
- Коммитить логическими шагами в свою ветку `task/<ID>`, не пушить.
